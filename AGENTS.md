# Agent Instructions

`README.md` is the repository entrypoint. `docs/` is the canonical detailed
documentation and source for the GitHub Pages presentation layer.

Treat `docs/_layouts/`, `docs/_includes/`, `docs/_data/`, and `docs/assets/`
as shared presentation support. Do not create a second documentation source or
duplicate the manual in the README. Maintain project navigation only in
`docs/_data/navigation.yml`.

Inspect existing documentation before changing this system. When an established
README is reshaped for Pages, retain `README.pre-pages.md` as a migration
record; do not maintain it as a second manual. Select the appropriate
orientation, guide, or reference writing mode before drafting.

Documentation discovery, local rendering, and structural changes do not
authorize deployment, publication, sanitization claims, a push, or changes to
private material. Review documentation structure, navigation, and public
content deliberately.
